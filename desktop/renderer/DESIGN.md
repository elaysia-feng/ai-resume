# AI Resume Forge 桌面端界面规范

## 产品场景

AI Resume Forge 是 Electron 求职准备工作台，主窗口最小尺寸为 1024 × 640。它不是宣传网站：桌面端打开后直接进入工作台，并自动使用固定的本地访客身份；不显示选择头像或名称的首次设置页。侧栏保留“账号登录”入口，后续邮箱登录接口接入该入口。已登录账号再次打开时保留账号状态。首页汇总状态和最近工作，但不规定先后步骤。

页面保留现有业务能力与接口。AI 修改显示依据和变化，由用户决定是否应用；没有真实记录时展示明确空状态，不填入演示统计或虚构活动。AI 服务会将当前任务所需内容发送到用户配置的模型服务，界面不得暗示所有处理都在本机完成。

## 视觉方向：构造网格工作台

采用克制的构造网格视觉：冷白画布、石墨文字、亮钴蓝 `#0057FF` 交互焦点。列线来自真实的页面布局和数据分区，不铺装饰性网格纹理。45° 斜线只在品牌或焦点控件中少量出现。工作入口用对齐的行和列表达，状态、内容与操作各有稳定位置。

首页第一屏用表格化入口列出简历、工作区对话和模拟面试。工作区对话用于通用求职问题与本地文件；简历编辑器内的模块 AI 助手绑定当前分区。各入口可独立进入；下方展示真实的最近工作和简历记录。简历编辑、模板、聊天、面试、历史、档案和设置沿用同一套冷白、细线、蓝色焦点语言。

## 简历模板

模板页从左侧“简历模板”入口打开。模板卡片用示例内容渲染真实 A4 缩略版式，选中卡片后在详情栏查看更大的完整预览，再应用到现有简历或新建简历。预览标明示例数据。保留现有模板 ID，并新增用途清晰的选项：`classic` 清晰投递版（ATS 单栏）、`modern` 职场进阶版（森林绿刊头、成果摘要与职业时间线）、`compact` 校招一页版（教育技能侧栏与项目经历主栏）、`academic` 科研学术版（刊头式抬头、教育档案与编号研究条目）、`creative` 作品案例版（作品案例编号与编辑式排版）、`dual-creative` 复合能力双栏版（窄能力索引栏与宽项目叙事栏）、`international-cv` 国际投递版（英文简历顺序与无头像 ATS 单栏）、`career-bridge` 转行衔接版（当前方向到目标职位的证据链）、`engineering` 工程实践版（技术索引与编号项目案例）、`leadership` 管理影响力版（管理职责与战略项目主线）、`public-service` 公职资历档案版（教育、证书与任职记录优先）、`sales-growth` 商务增长版（客户与市场成果主线、技能工具侧栏）。十二套分别使用固定浅色纸面配色，保证屏幕预览和 PDF 导出一致。

不使用营销式大标题、装饰性插画、无数据的统计卡、整页渐变、发光、玻璃效果或伪造的AI建议。版面强调真实内容与可操作的控件。

## 布局

- 应用导航固定在左侧，展开宽度 258px，收起宽度 64px。
- 主内容区独立滚动，常规内边距使用 --ui-space-8，窄窗口使用 --ui-space-6。
- 首页工作入口用真实 CSS Grid 对齐名称、状态和操作；最近工作与简历列表并列，窄窗口下改为纵向排列。
- 聊天和简历编辑器保留各自的工作区工具栏，不重复绘制全局导航。
- 访客工作台、登录和注册页面复用相同的品牌标识、网格线和表单控件；本地身份设置页不参与桌面端首次启动流程。

## 颜色、字体与图标

唯一 UI token 来源是 src/styles/design-system.css。应用交互色通过 --ui-accent 使用钴蓝，网格线使用 --ui-grid-line 与 --ui-grid-line-strong。--ui-brand-* 保留给简历模板的样式选择，应用外壳改色不改变用户导出的简历模板。

字体只使用本机系统字体栈，不加载在线字体。界面图标通过 src/components/common/AppIcon.vue 使用内置路径。品牌标记由 src/components/common/AppBrandMark.vue 提供，是按 5 × 5 网格构造的字母 A。桌面程序图标的 SVG 源文件为 desktop/build/icon.svg，Windows 多尺寸资源为 desktop/build/icon.ico；运行 npm run build:icon 可重新生成两者。

## 交互与无障碍

- 所有可点元素都需有 hover、focus-visible 与 disabled 状态。
- 状态不能只靠颜色区分，需配文字标签。
- 加载、错误和空状态均要清楚，并提供合适的重试或下一步操作。
- 保持键盘 Tab 顺序、Enter/Space 操作和可见焦点。
- 在 1024 × 640 到 1920 × 1080 范围内避免横向滚动和文字遮挡；尊重减少动态效果偏好。

## 实现边界

只调整界面结构与样式、品牌标识和桌面图标。不绕过 Java 接口直接访问 Python，不改变简历、会话、面试及设置的业务行为。新增的普通 UI 图标仍使用内置 AppIcon；品牌图形只在品牌标记组件和桌面图标资源中绘制。
